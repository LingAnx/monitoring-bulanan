Sistem Pelaporan Kinerja Bulanan

KSOP Kelas II Cirebon — 3 Level Verifikasi: Pegawai → Admin Seksi → Kepala Kantor

Masuk Sistem Pelajari Alur
📝

1. Buat Laporan

Pegawai mengisi laporan kinerja bulanan: judul, periode, capaian, kendala, rencana tindak lanjut.

🔍

2. Verifikasi Seksi

Admin Seksi memeriksa dan dapat meminta revisi atau meneruskan ke Kepala Kantor.

✅

3. Persetujuan

Kepala Kantor memberikan persetujuan final, atau mengembalikan laporan untuk revisi.
